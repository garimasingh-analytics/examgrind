# Tracking Audit: 2026-08-14

**Codebase:** ExamGrind
**SDK:** GA4 `gtag.js`, Google Ads conversion helper, Meta Pixel helper

## Current Tracking Inventory

The typed `ANALYTICS_EVENTS` boundary currently defines 36 browser events. Calls are present across the public landing, five-question diagnosis, Google-auth return, Home handoff, daily mission, quiz/mock attempts, results and recovery flows, access/payments, and public Study Hub.

The acquisition-to-activation sequence has active browser calls for `landing_book_opened`, `landing_cta_clicked`, `landing_exam_selected`, `diagnosis_started`, `diagnosis_question_answered`, `diagnosis_completed`, `diagnosis_result_viewed`, `diagnosis_signup_clicked`, `diagnosis_signup_completed`, `diagnosis_handoff_viewed`, `diagnosis_handoff_action`, `study_hub_viewed`, `study_guide_viewed`, `quiz_started`, and `repair_round_started`.

`study_hub_viewed` is called from the public guides index and official updates desk. `study_guide_viewed` is called from individual public guide pages. The `read_guide` value of `diagnosis_handoff_action.action` is called from the Home diagnosis handoff card.

## Identity Management

| Call Type | Present | Details |
|---|---|---|
| identify() | No | No GA4 user ID, email, name, or traits are sent. |
| group() | No | ExamGrind is B2C and has no group hierarchy. |
| page()/screen() | GA4 default config | `gtag.js` is configured after explicit marketing consent. |
| reset()/logout | No | No browser analytics identity is set. |

## Observed Patterns

- **Naming style:** snake_case.
- **Call routing:** centralized through `lib/product-analytics.ts`; Google Ads and Meta conversions use focused helpers.
- **Consent:** `MarketingTracking` sets denied defaults, then enables tags and events only after the visitor grants analytics/ads consent.
- **Properties:** public Study Hub events use known exam labels and guide slugs; the core wrapper does not transmit identity, question text, answers, payment IDs, or typed topic searches.
- **Delivery:** browser calls are non-blocking and are not awaited by learning or billing flows.
